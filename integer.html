Степень с нулевым показателем

Для любого числа a, не равного нулю: a0 = 1

Выражение 00 не имеет смысла.
Примеры:
  • 50 = 1
  • (-7)0 = 1
  • (2/3)0 = 1

Степень с отрицательным показателем

Для любого числа a, не равного нулю, и натурального n:

a-n = 1 / an
Важно: основание степени не может равняться нулю, так как деление на нуль невозможно.
Примеры:
  • 2-3 = 1 / 23 = 1 / 8
  • 10-2 = 1 / 102 = 1 / 100 = 0,01
  • (3/4)-2 = (4/3)2 = 16 / 9

Свойства степени с целым показателем

Все свойства, изученные для натурального показателя, сохраняются для любого целого показателя (при условии, что основания не равны нулю).

1. am · an = am + n
2. am : an = am - n
3. (am)n = am · n
4. (a · b)n = an · bn
5. (a / b)n = an / bn

Примеры применения

Задание 1. Упростите: x4 · x-7

x4 · x-7 = x4 + (-7) = x-3 = 1 / x3

Задание 2. Вычислите: (2-1 + 3-1)-1

2-1 = 1/2,   3-1 = 1/3

1/2 + 1/3 = 5/6

(5/6)-1 = 6/5 = 1,2

Задание 3. Представьте в виде степени: 8 · 2-5

8 = 23, значит: 23 · 2-5 = 23 + (-5) = 2-2 = 1/4
